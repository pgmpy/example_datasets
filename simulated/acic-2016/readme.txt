Atlantic Causal Inference Conference (ACIC) 2016 Benchmark Dataset

Original source:
https://github.com/vdorie/aciccomp

This dataset was preprocessed for use with pgmpy.

Files:
- acic.2016.sim.1.mixed.txt

Columns:
- x1-x58 : covariates
- z : treatment assignment
- y : observed outcome
- mu0 : expected untreated outcome
- mu1 : expected treated outcome
